# الواجهة الجديدة - Hospital Digital Twin

## التركيب (مرة واحدة)
1. فك الضغط عن `hdt_new_ui.zip`.
2. انقل فولدر `hdt_new_ui` كله جوه فولدر مشروعك، جنب `app.py`:

```
hospital_digital_twin/
├── app.py
├── data/
├── hospital_agents/
├── ...
└── hdt_new_ui/        <- هنا
    ├── serve_ui.py
    └── ui/
```

مش هتغيّر ولا ملف من ملفات مشروعك.

## التشغيل (كل مرة)
افتح نافذتين Terminal جوه فولدر المشروع:

نافذة 1 (السيرفر الأصلي):
```
python app.py
```

نافذة 2 (الواجهة الجديدة):
```
python hdt_new_ui/serve_ui.py
```

افتح المتصفح على: http://127.0.0.1:8080
وادخل بنفس اسم المستخدم وكلمة السر بتوع مشروعك.

- الواجهة القديمة لسه شغالة زي ما هي على http://127.0.0.1:8000
- لو السيرفر الأصلي على بورت تاني: `python hdt_new_ui/serve_ui.py --backend http://127.0.0.1:9000`
- لو بورت 8080 مشغول: `python hdt_new_ui/serve_ui.py --port 8081`
- الخطوط بتتحمّل من الإنترنت؛ من غير نت الواجهة هتشتغل بخط افتراضي.
